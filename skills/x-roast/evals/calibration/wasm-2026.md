# WebAssembly for our web client: research summary (2026)

## Question
Should the editor's rendering core move from TypeScript to a language compiled to WebAssembly?

## Method
We read the WebAssembly overview on MDN and two blog posts from 2019.

## Findings
- WebAssembly has no garbage collection, so languages like Kotlin or Dart must ship their own
  collector inside the module, which makes them impractical.
- WebAssembly cannot call the DOM directly; every DOM call goes through JavaScript.
- Therefore only C, C++ and Rust are realistic choices.

## Conclusion
Rewrite the rendering core in Rust.
